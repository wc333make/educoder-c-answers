## 命名规则

- 目录：`作业序号_作业原名[作业ID]`，按仓库原始顺序排列。
- 文件：`关卡序号_题目名.c/.h`；序号就是平台上的关卡序号，遇到留空题序号会跳号，属正常现象。
- 一道题要改多个平台文件时（函数题的 main + .h、多文件工程题），文件名带 `__原平台文件名` 后缀，同一前缀即同一道题。
- 题名里的 `/` 在文件名中写作 `_`（Windows 文件名不允许 `/`）；`[` `]` 为作业 ID 标记。

## 怎么用

- 完整程序题（`.c`）：整份文件覆盖平台上的同名源文件即可。
- 函数题 / 表达式题（`.h`）：只覆盖平台的头文件。文件里已经是该题要求的完整函数或单个表达式，不是可独立编译的程序，直接编译会报错，属预期。
- 每道题要覆盖哪个线上文件，见下面清单的 “平台路径” 列（相对平台工程根目录）。
- 文本编码：全部文件为 UTF-8 with BOM（开头带 BOM 标记，记事本 / VS / VS Code / Dev-C++ 都能正确识别中文）、换行 CRLF。若你的编辑器仍显示乱码，把编码手动切到 “UTF-8” 即可；复制粘贴进头歌网页编辑器不受 BOM 影响。
